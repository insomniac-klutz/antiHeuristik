# Coding Fluency

Not leetcode. Functional fluency for the kind of code you actually write.
These are drill targets — hit them when a Build exposes the gap.

## Python Patterns
- [ ] async/await — write a concurrent API caller from scratch
- [ ] Generators — streaming data processing without loading all into memory
- [ ] Decorators — retry, logging, timing, caching
- [ ] Context managers — resource cleanup, DB connections, temp files
- [ ] Type hints — typing module, Generics, Protocols, when types help vs hinder
- [ ] Dataclasses / Pydantic — structured data, validation, serialization

## Data Manipulation
- [ ] pandas — groupby, merge, pivot, window operations
- [ ] polars — when it beats pandas, lazy evaluation
- [ ] JSON/XML parsing — nested structures, streaming parsers for large files
- [ ] Regex — text extraction patterns you'd use in NER/preprocessing
- [ ] CSV/Parquet — format tradeoffs, chunked reading

## API Integration
- [ ] REST client design — clean, reusable, testable
- [ ] Retry logic — exponential backoff, jitter, max retries
- [ ] Rate limit handling — token bucket, sliding window, 429 response handling
- [ ] Streaming response processing — SSE, chunked transfer
- [ ] Webhook design — receiving async callbacks
- [ ] Error handling — timeout, connection errors, malformed responses

## SQL
- [ ] Window functions — ROW_NUMBER, RANK, LAG/LEAD, running totals
- [ ] CTEs — recursive and non-recursive, readability vs performance
- [ ] Self-joins — hierarchical data, comparing rows within same table
- [ ] Subqueries vs joins — when each is clearer/faster
- [ ] Query optimization — EXPLAIN plans, index usage, N+1 detection
- [ ] Complex aggregations — HAVING, GROUPING SETS, CUBE/ROLLUP
