# Grind — Topic Seed Bank

Every topic extracted from the builds, organized by domain.
Two purposes:

1. **When a Build hits a wall**, find the relevant topic here, drill it, move on.
2. **When you need a new Build idea**, scan this list for clusters of uncovered topics and design a Build that forces them.

Mark topics as they get covered by Builds or drills. A topic is "covered" when you can explain it cold in 2 minutes, not when you've read about it.

---

## How to use this

- `[ ]` = untouched
- `[~]` = encountered in a Build but not confident yet
- `[x]` = can explain cold, have built something that uses it
